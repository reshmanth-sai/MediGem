# MediGem Responsive & Breakpoint Specifications

> **Desktop, Tablet, and Mobile Breakpoint Rules**

- **Desktop (`≥ 1024px`)**: Full 3-column proportional grid + expanded sidebar.
- **Tablet (`768px – 1023px`)**: Collapsible sidebar + 2-column workspace layout.
- **Mobile (`< 768px`)**: Stacked single-column layout + drawer navigation menu.
