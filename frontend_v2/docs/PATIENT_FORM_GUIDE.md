# MediGem Patient Demographics & Vitals Form Guide

> **Form Field Specifications, Default Masks & Vitals Ranges**

- **Patient Name**: Required text input.
- **Age**: Required integer (1–120).
- **Gender**: Male, Female, Other.
- **Heart Rate**: Optional integer (bpm).
- **Blood Pressure**: Systolic / Diastolic mmHg.
- **Temp / SpO2**: Celsius & % oxygen saturation.
