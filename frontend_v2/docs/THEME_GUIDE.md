# MediGem Theme & CSS Design Tokens Guide

> **CSS Custom Properties, Light/Dark Modes, and Palette Tokens**

---

## 🎨 Token Variable Map

- `--teal-600`: `#0D9488` (Primary Teal Accent)
- `--teal-700`: `#0F766E` (Dark Header Gradient Accent)
- `--slate-50`: `#F8FAFC` (Light Background)
- `--slate-900`: `#0F172A` (Primary Dark Text & Night Mode Background)
- `--emergency-bg`: `#FEE2E2` (Emergency Alert Background)
- `--emergency-text`: `#B91C1C` (Emergency Alert Text)

All contrast ratios comply with WCAG 2.1 AA/AAA standards.
