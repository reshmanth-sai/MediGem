# MediGem Case History Architecture

> **Clinical Case History, Filters, and Insights Dashboard Specification**

---

## 📊 Clinical Insights Dashboard Metrics

1. **Total Cases**: Total count of completed clinical reasoning sessions.
2. **Emergency Cases**: Count & percentage of cases triggering emergency gates.
3. **Average AI Confidence**: Mean confidence score across completed cases.
4. **Average Processing Time**: End-to-end local latency average.
5. **Most Common Analysis Type**: Primary modality distribution.
