# MediGem Page Layout Templates Guide

> **Dashboard, Workspace, Results, and History Templates**

---

## 📐 Template Index

1. **`DashboardTemplate`**: Overview Grid layout (`grid-cols-1 md:grid-cols-4`).
2. **`WorkspaceTemplate`**: 3-Column proportional workspace (Left Sidebar 25%, Center Workspace 35%, Right Results 40%).
3. **`ResultsTemplate`**: Case results display layout.
4. **`HistoryTemplate`**: Timeline list layout.
