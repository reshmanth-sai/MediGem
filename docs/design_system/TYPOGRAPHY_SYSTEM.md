# MediGem Typography System

> **Font Hierarchy, Typescale, Line-Heights & Clinical Usage Rules**

---

## 🔤 Font Family Specification

MediGem standardizes on **Inter** (Google Fonts)—a highly legible, variable sans-serif font engineered for high-density UI displays.

- **Primary Font**: `'Inter', system-ui, -apple-system, sans-serif`
- **Monospace Font**: `'JetBrains Mono', 'Fira Code', monospace` (Used for Patient IDs, Code, and Referral Memorandums)

---
